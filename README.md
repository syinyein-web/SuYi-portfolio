# Su Yi Nyein: Portfolio Website

A single-page, multi-section portfolio. Everything (HTML, CSS, JavaScript and images) is inside `index.html`, so there is nothing to build or install.

## Deploy (pick one)

**Netlify (easiest)**
1. Go to https://app.netlify.com/drop
2. Drag this folder (or the unzipped `index.html`) onto the page.

**GitHub Pages**
1. Create a new GitHub repository and upload `index.html`.
2. Go to Settings > Pages, choose the `main` branch and the root folder, then save.

**Vercel**
1. Import the repository (or run `vercel` in this folder).
2. Use the default settings. No build command is needed.

## Edit
Open `index.html` in any text editor. Page sections are marked with comments such as `<!-- PROJECTS -->`.
